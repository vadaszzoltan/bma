# Ajánlatkérés v2: munkaállapot

Az ügyfél új szolgáltatás-struktúrája lecseréli a mostani ajánlatkérési rendszert.

- [ugyfel-kerdesek.md](ugyfel-kerdesek.md) – amit az ügyfélnek küldtünk
- [elemzes.md](elemzes.md) – a válaszuk értelmezése és a változások

## Nyitott visszakérdések az ügyfél felé

1. Gáz- és áramcsatlakozás tényleg kikerül a bekötések közül?
2. Műszaki dokumentáció és használatbavétel megszűnik, vagy kimaradt?
3. Terv-ellenőrzés: kivitelezési fázisnál automatikusan kerüljön be, vagy csak tájékoztatás?
4. Román szakkifejezések (DTAC, PT, DDE, SF/DALI, ISU) megjelenítése HU/EN felületen.
