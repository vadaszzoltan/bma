# Példa üzenet Claude Designnak

Másold be (és csatold a mappa fájljait):

---

Készíts / frissíts implementációs csomagot a Cursor agentnek.

Kövesd szigorúan ezeket a fájlokat:
- `CLAUDE-DESIGN-BRIEF.md`
- `PACKAGE-TEMPLATE.md`
- `CHECKLIST.md`
- `BMA-KONTEXTUS.md` (ehhez a projekthez)

Elvárás:
1. Egy `bma-redesign-cursor.zip`, benne a teljes mappa (README, PROMPT, VALTOZASOK, SZOVEGVALTOZASOK, css/, markup/).
2. A PROMPT első lépése csak feltérképezés legyen; hiányzó fájlnál álljon meg.
3. Ne találgass PHP pathot, enqueue handle-t, taxonómiát vagy üzleti számot — `[HELYŐRZŐ]` + „Cursor derítse fel” / „ügyfél tölti ki”.
4. A szövegeltéréseket tételesen írd a SZOVEGVALTOZASOK.md-be.
5. Ha kaptál Cursor-felderítési jelentést, készíts `FELDERITES-UTAN.md`-t, ami felülírja a README téves feltételezéseit.
6. Átadás előtt futtasd a CHECKLIST.md-t.

Kimenet: a zip + rövid lista, mit változtattál az előző csomaghoz képest.
