# Figma import – Ajánlatkérés részletes nézet

Admin ajánlatkérés (kérelem) részletes nézet mockup a jelenlegi `request-detail.php` alapján.

## Fájlok

| Fájl | Használat |
|------|-----------|
| `bma-ajanlatkeres-reszletes-nezet.svg` | Figma natív import (szerkeszthető vektorrétegek) |
| `bma-ajanlatkeres-reszletes-nezet.html` | html.to.design / böngészős előnézet |

## Import SVG-ből (ajánlott)

1. Nyisd meg a Figmát
2. **File → Place image…** (vagy `Cmd/Ctrl + Shift + K`), vagy húzd rá az SVG-t a canvasre
3. Dupla katt / `Enter` a csoportba, majd **Ungroup** (`Cmd/Ctrl + Shift + G`) a rétegekhez
4. A panelnevek megmaradnak (`Panel / Ügyféladatok`, `Button / …` stb.)

## Import HTML-ből

1. Telepítsd a [html.to.design](https://www.figma.com/community/plugin/1159123024924461424) plugint
2. Nyisd meg az HTML-t böngészőben, vagy add meg a fájl útvonalát a pluginban
3. Importáld frame-ként
